# UI／UX 設計規格

版本：1.0｜2026-10-14｜規格及最新座位圖已核可，單檔 MVP 已完成。功能以 [PROJECT_SPEC](PROJECT_SPEC.md) 為準，範圍見 [SEAT_INVENTORY](SEAT_INVENTORY.md)，逐排集合見 [SEAT_ROWS](SEAT_ROWS.md)，流程見 [GAME_FLOW](GAME_FLOW.md)。

## 1. 設計方向

深色售票介面搭配紫藍霓虹、噴霧粒子與舞台光束。首頁呈現演唱會海報感，操作頁優先維持文字與座位辨識度。第一版沒有音效與背景音樂。

| 元素 | 建議規格，色碼可在視覺設計時微調 |
| --- | --- |
| 頁面底色 | 近黑 #090D18 |
| 卡片 | 深藍灰 #151C2E，清楚邊界 |
| 品牌色 | 紫 #A78BFA、藍 #60A5FA |
| 主要文字 | 近白 #F3F4F6；次要文字 #B8C2D8 |
| 危急狀態 | 紅色配文字／圖示，不只靠顏色 |
| 字體 | 優先系統繁體中文字體，英文字標可加字距，避免依賴外部字型服務 |
| 金額 | NT$6,280 等整數新臺幣格式 |
| 主按鈕 | 高對比，標籤說明下一個動作 |

分區名稱與原圖色系用於導航，售出／選取狀態另用輪廓、圖樣及圖例區分，避免「藍區」被誤解為可售狀態。

已確認票價：VIP A～E 為 NT$6,280；黃／橙／藍 B 區（含單雙號）為 NT$5,480；藍 A 區除藍1A-1、藍5A-3 外為 NT$4,280；黃／橙 A 區及藍1A-1、藍5A-3 為 NT$3,680。模擬無障礙席固定 NT$3,680，優先於分區價。總覽、單區、摘要、結帳及票券皆使用相同對照。

## 2. 共通畫面框架

- 頂端：CONCERT QUEST、The Ticketing Challenge、遊戲模擬標示。
- 進度：倒數／排隊／選位／結帳／結果，清楚標出當前階段。
- 選位與結帳固定顯示同一個「剩餘時間」，不可遮住座位或輸入欄。
- 桌機座位圖與訂單摘要並排；手機摘要使用可展開區塊，主要操作固定在底部並預留安全區。
- 載入、錯誤及成功都以文字說明，不依賴動畫。
- 首頁可展開最佳紀錄與最近 10 局，避免另建複雜導航。

## 4. 座位圖互動

### 總覽

- 自繪 SVG 呈現上方主舞台、中央走道、菱形延伸舞台、VIP A～E 與已核對的看台分區。
- 已確認重新繪製互動圖，不使用原圖作底圖、不直接展示原始圖片；來源說明保留於文件。
- 分區區塊顯示標籤及可售數；可透過鍵盤與點擊進入。
- 圖上保留舞台方向，標示「依參考圖片繪製，非官方售票配置」。
- 已確認依「林口體育館區域圖.jpg」分區，不另外新增綠區。
- 無障礙標記區開放 4 席模擬座位，單區圖排列為「模擬第 1 排、1～4 號」，每席 NT$3,680；保留圖示並標示「模擬無障礙席，配置與購票規則非真實售票資訊」，不驗證或蒐集資格資料。選位摘要與票券同樣保留模擬標示，價格不代表真實票價或優惠。
- 不直接使用原演唱會海報文字當成遊戲內容。

### 單區完整圖

- 顯示分區原名、樓層（可確認時）、價位、排數／座號、返回總覽、縮放與重設視角。一般看台整個分區同價，不依排數拆價；模擬無障礙席固定 NT$3,680，須另外清楚標示。
- SVG 保留逐排缺格與座號，不以矩形自動補滿；無法辨識而補入的資料帶模擬標記。
- 逐排以 SEAT_ROWS 有效集合建立座位；缺格不繪製成售出席、不提供可點擊熱區。內部缺號保留空間，不壓縮重編座號。本次 25 區新補缺格全標示模擬；正規化矩陣預覽不是場館實際朝向。
- 各區分別保存排號與座號的增加方向，不一律把「排」畫成橫列。黃1B單已確認排號由左向右增加，第 1 排最左、第 15 排最右；單區圖須保留此方向並標示排號軸。
- 可選：清楚外框與可用圖樣；已售：暗色與斜線／叉號；已選：亮色粗框與勾選。
- 座位狀態的程式語意、圖例與文字名稱須一致。
- 點座位直接選／取消；桌機懸停或鍵盤聚焦可看詳細資料，手機不可依賴懸停。
- 當售出狀態改變時只更新受影響席位，避免重新繪圖造成視角、焦點及捲動跳動。

### 選位摘要

每局進入選位時，張數控制預設為 1 張，可切換為 2 張；新局不沿用上一局的設定。從結帳返回則維持本局目標張數。

逐席列出分區、排數、座號、單價、取消按鈕與模擬標記；底部顯示已選／目標張數及總額。點明細可切回對應分區，不更動選位。

## 5. 手機與鍵盤操作

- MVP 必須能在手機完整通關，建議驗收寬度為 360、390、768px，以及桌機 1280px 以上。
- 手機採「總覽 → 單區完整圖」，不要求在全場密集座位圖直接點選。
- 單區支援按鈕放大／縮小與受限容器拖曳；放大後提供足夠點選範圍，常用控制目標建議至少 44px。
- 不在縮得過小的座位上擴大隱形熱區造成重疊；提示先放大。初始單區視圖可看全區，選位時允許放大。
- 以手勢位移閾值區分拖曳與點選，避免拖動後誤選座位；雙指手勢可列後續優化。
- 全頁不橫向溢出；座位視窗內可平移，固定摘要不能遮住圖與驗證欄。
- 分區與主要按鈕可 Tab 操作；大量座位建議以單一進入焦點搭配方向鍵移動、Enter／Space 選取，避免逐席數千次 Tab。
- 聚焦座位朗讀分區、排、號、價位與狀態；可售／已選／售出不可只用顏色表達。
- 4 碼驗證碼使用清晰文字，提供同等可讀取內容，不做扭曲文字障礙；此為遊戲步驟，不宣稱安全驗證。

## 6. 提示、對話框與動態回饋

| 情境 | 建議文字／行為 |
| --- | --- |
| 時間提醒 | 60 秒及 30 秒以文字提醒，最後 10 秒加明顯視覺，不強烈閃爍 |
| 已選滿 | 「已選滿 2 張，請先取消一席再更換。」依實際目標更新 |
| 庫存不足 | 「剩餘座位不足 2 張，你可以改買 1 張。」提供張數控制，不自動改單 |
| 返回結帳前一步 | 「返回將釋放全部已選座位，原座位可能被搶走；倒數持續。」按鈕為「留在結帳」與「釋放並返回」 |
| 兩張改一張 | 列出兩席供選擇保留，提供確認／取消；對話框期間時間繼續 |
| 錯誤驗證 | 「驗證碼不正確，請再試一次。」保留座位，指出可換碼 |
| 完售 | 「座位已全數售出，本次挑戰失敗。」 |
| 逾時 | 「選位與結帳時間已用完，本次挑戰失敗。」 |
| 中斷 | 「未完成挑戰不會保留，請重新開始。」重整可辨識時補上中斷提示 |
| 儲存失敗 | 「此瀏覽器目前無法保存紀錄，本次仍可正常遊玩。」 |

對話框管理焦點，關閉後回觸發按鈕；若倒數結束，直接轉結果並關閉對話框。倒數不每秒透過讀屏播報，僅於重要門檻提醒；座位售出訊息合併顯示，避免洗版。

動畫用於倒數光暈、粒子與成功回饋，不影響操作判定。尊重 prefers-reduced-motion，減少動畫後仍保有完整訊息。

## 7. 結果與票券

成功頁同時顯示總流程時間及選位結帳時間，說明最佳紀錄依後者比較。兩張分別產生票券卡，載明虛構團體、演出名稱、日期、場館、分區、排數、座號、單價，以及「模擬票券，無入場效力」。若座號屬補足資料，額外標示「含模擬座位配置」。

第一版不提供票券下載、真實 QR 驗票或付款資訊；可用裝飾性圖形呈現票面，但不製造可誤解為有效入場的識別內容。
