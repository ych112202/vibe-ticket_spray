## 1. 如何閱讀

- 共 37 個具名分區，加 1 個模擬無障礙席入口。
- 「已確認」為使用者先前已採用的遊戲配置，不代表官方證實。
- 使用者已表示「此修正清單皆通過」，本清冊所列排號、座號包絡、黃4B雙逐排表及已提出方向均確認採用。部分依區域圖端點與格線整理，部分為原圖細字不清時的模擬設定；通過遊戲配置不代表官方資料已核實。
- **座號範圍是分區包絡，不代表每一排都有完整範圍。**本次已在 SEAT_ROWS 補上全部分區逐排有效集合與缺格；原圖難辨識部分維持模擬標示。
- 不規則區席數由逐排有效集合加總，不以包絡長度乘排數，也不把缺格算成已售出座位。
- 「單」只含奇數，「雙」只含偶數；A 區與 VIP 不因編號而自動套用單雙號限制。
- 排號可包含 0：區域圖部分 A 區確有綠色 0 標記。已確認採用表中含 0 的排號，不將 0 改成 1 或平移所有排號。
