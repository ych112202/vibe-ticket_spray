## 如何閱讀

- 座位格內顯示座號，綠色小字為排號；0 排照資料保留。
- SVG 可放大查看，滑鼠停留於座位時可讀取分區、排號、座號與模擬票價。PNG 不含懸停資訊。
- 顏色代表票價，不代表可選／售出狀態：金色 6,280、藍色 5,480、青綠色 4,280、粉色 3,680 元。青綠色是價位色，並未新增「綠區」。
- 缺格不畫座位，單雙號不重新壓縮編號；VIP D 沒有第 13、14 排。
- 藍1A-1、藍5A-3 維持 3,680 元；模擬無障礙席也固定 3,680 元。
